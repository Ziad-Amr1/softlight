# 🌿 Softlight

![Unity](https://img.shields.io/badge/Unity-6-black?logo=unity)
![C#](https://img.shields.io/badge/C%23-.NET-purple)
![Status](https://img.shields.io/badge/status-early--development-orange)
![License](https://img.shields.io/badge/license-MIT-green)

A cozy 2D top-down RPG built with **Unity 6**.

Softlight is a learning-driven game development project focused on building a complete RPG from the ground up while following clean architecture, maintainable code, and scalable systems.

> **Project Status:** 🚧 Early Development

---

## ✨ Vision

Softlight aims to become a relaxing RPG where players can explore a peaceful world, interact with NPCs, gather resources, complete quests, and uncover the story of the world.

The project emphasizes both gameplay quality and software engineering practices.

---

## 🎮 Current Features

- ✅ Player movement
- ✅ Input System (Unity Input System)
- ✅ Smooth camera follow
- ✅ Blend Tree animations
- ✅ Directional idle and movement animations
- ✅ Tilemap-based world
- ✅ Collision system
